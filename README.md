# 哈尔滨工业大学航模协会 · HITMA

协会展示主页，包含协会介绍、技术方向、竞赛荣誉、人才培养、活动科普与交流入口。内容和实际照片来自用户提供的《哈工大航模协会简介.pptx》。协会是科技类学生团队，页面采用企业官网的呈现方式，未将其改称企业。

## 预览与发布

网站使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

本地直接打开 `index.html`，或在项目目录执行：

```sh
python -m http.server 8080
```

浏览器访问 `http://localhost:8080`。

GitHub Pages：在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。启用后地址为 https://hitma2026.github.io/ 。

## 维护

- `index.html`：页面结构、介绍、荣誉、合作入口及 SEO 信息。
- `styles.css`：深蓝与浅青配色、响应式布局、可访问性和减少动态效果支持。
- `script.js`：移动导航、项目分类筛选、项目详情弹窗和滚动显示。
- `assets/`：从介绍 PPT 提取并压缩为 WebP 的照片及协会徽标。

未提供邮箱、电话或招新群信息，因此交流按钮指向本仓库的新建 Issue 页面；仓库需保持 Issues 功能开启。访客提交 Issue 才会发送留言，网页不会自动创建 Issue。之后可替换为协会确认的正式联系方式。

## 内容口径
